핵심 성장 동력 3가지
1
Azure — 성장률 +43%·연매출 $100B 돌파
Q4 FY26 Azure 및 기타 클라우드 매출이 43% 성장하며 Q3의 40%에서 재가속했다. 상업 잔여계약은 84% 증가한 $678B로 확대돼 AI 인프라 투자의 매출 전환 가시성을 높였다.
2
Microsoft 365 Copilot — 유료 시트 3,000만+
유료 시트가 3,000만 개를 넘어서며 기업용 AI의 실제 과금 기반이 확대됐다. M365 Commercial Cloud 매출도 Q4 FY26에 14% 성장했다.
3
Microsoft Cloud — 분기 $59.3B·+27%
Intelligent Cloud 매출 $39.3B(+32%)와 Microsoft Cloud 매출 $59.3B(+27%)가 전사 성장을 견인했다. 다만 Q4 설비투자 $35.8B가 현금흐름 전환 속도를 좌우한다.
핵심 투자 논리 (적정)
Azure +43%, Microsoft Cloud $59.3B(+27%), 상업 잔여계약 $678B(+84%)는 AI 인프라 수요와 매출 가시성이 동시에 강화되고 있음을 보여준다. Microsoft 365 Copilot 유료 시트 3,000만 개와 Azure 연매출 $100B 돌파가 밸류에이션 프리미엄의 근거다. 반면 FY26 설비투자 $115.9B와 Q4 $35.8B는 FCF를 압박하므로, FY27에는 성장률뿐 아니라 투자 대비 현금수익률 개선이 핵심이다.
